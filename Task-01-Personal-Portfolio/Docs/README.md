# Personal Portfolio

Hi, I'm Alazar, a Full-Stack Developer. I built this portfolio to
introduce myself, showcase the technologies I work with, and share
some of the projects I've worked on.

The goal of this project is to have one place where people can learn
more about me, see my work, and get in touch with me.

## About the Project

This is a responsive personal portfolio built with React and Tailwind
CSS.

I wanted the website to be simple, modern, and easy to navigate while
still showing my skills and experience as a developer.

The portfolio includes sections for:

- About me
- Skills and technologies
- Projects
- Contact information
- Resume / CV

It also supports light and dark mode.
